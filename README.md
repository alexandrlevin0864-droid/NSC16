# NSC16

Твик для джейлбрейк-устройств iPhone (Theos): превращает устройство в настольные часы, пока оно заряжается.

- Чисто чёрный фон для экономии энергии на OLED-экранах
- Крупное текущее время в 12/24-часовом формате (по желанию: дата, заряд батареи)
- Экран не гаснет, пока твик активен
- Регулируемая яркость, чтобы не слепить ночью
- Пиксель-шифтинг (лёгкое случайное смещение элементов) для защиты OLED от выгорания
- Панель настроек в системном приложении «Настройки»

## Совместимость

- Целевая iOS: **15–16** (SDK сборки — iOS 16.5, arm64 + arm64e)
- Требуются: `mobilesubstrate (>= 0.9.5000)`, `preferenceloader (>= 2.2.4)`
- Тестирование: устройства с OLED-экраном (iPhone X/XS/11 Pro/12/13/14 Pro)

## Сборка

Нужен [Theos](https://theos.dev). Сборка на Linux так же поддерживается.

```bash
make package FINALPACKAGE=1
# готовый пакет: packages/com.example.nsc16_1.0.0_iphoneos-arm.deb
```

### Rootless (Dopamine / Palera1n rootless)

В `Makefile` раскомментируй:

```make
export THEOS_PACKAGE_SCHEME = rootless
```

## Установка

Загрузи пакет на устройство по SSH и установи:

```bash
scp packages/com.example.nsc16_1.0.0_iphoneos-arm.deb root@<IP>:/ 
ssh root@<IP> "dpkg -i /com.example.nsc16_1.0.0_iphoneos-arm.deb && sbreload"
```

Или установи `.deb` через Sileo / Installer.

## Настройки

После установки и респринга: **Настройки → NSC16**

- **Включить** — мастер-переключатель твика
- **24-часовой формат** — переключение 12/24
- **Показывать секунды** — отображение секунд
- **Показывать дату** — строка с датой
- **Показывать заряд батареи** — уровень заряда и шкала
- **Пиксель-шифтинг** — защита OLED (элементы плавно смещаются каждые ~8 с)
- **Яркость** — яркость экрана во время показа часов

## Структура

```
NSC16/
├── control                  # метаданные пакета
├── Makefile                 # сборка твика + бандла настроек
├── NSC16.plist              # вход в «Настройках» (PreferenceLoader)
├── Filter.plist             # инъекция в SpringBoard
├── Tweak.x                  # логика твика (Logos)
└── NSC16Settings/           # бандл панели настроек
    ├── NSC16Settings.m
    └── Resources/Root.plist
```
